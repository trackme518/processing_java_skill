# Processing Examples Index

All examples live under `examples/`. Each is a Processing sketch folder with `.pde` file(s).

Paths are relative to the skill directory:
`skills/processing-cli-skills/examples/<Category>/<Subcategory>/<SketchName>/<SketchName>.pde`
